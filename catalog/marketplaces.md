# Marketplaces & registres de plugins

Sources depuis lesquelles installer des plugins/skills en lot.

---

### Claude Plugins Official
- **Lien** : `github.com/anthropics/claude-plugins-official`
- **Type** : marketplace de plugins
- **Compatibilité** : Claude Code
- **Installation** : ajoutée comme marketplace connue (`claude-plugins-official`)
- **À quoi ça sert** : catalogue officiel Anthropic de plugins pour Claude Code.

---

### Skills for Fabric (fabric-collection)
- **Lien** : `github.com/microsoft/skills-for-fabric`
- **Type** : marketplace de plugins
- **Compatibilité** : Claude Code
- **Installation** : marketplace `fabric-collection` ; active `fabric-skills@fabric-collection`
- **À quoi ça sert** : source du plugin `fabric-skills` (voir [skills.md](skills.md)).

---

### ponytail
- **Lien** : `github.com/DietrichGebert/ponytail`
- **Type** : marketplace de plugin (mono-plugin)
- **Compatibilité** : Claude Code (le plugin lui-même est agnostique, 15+ plateformes)
- **Installation** : `claude plugin marketplace add DietrichGebert/ponytail`
- **À quoi ça sert** : source du plugin `ponytail@ponytail` (voir [frameworks.md](frameworks.md)).
